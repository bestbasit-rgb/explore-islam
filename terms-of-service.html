4.1 Internal-only use

4.2 YouTube API usage

The tool uses the YouTube Data API v3 strictly to publish videos to the channel owner's own channel. Permitted API calls are:

  • videos.insert — upload the video file
  • videos.update — set the title, description, and category
  • thumbnails.set — attach a custom thumbnail
  • playlistItems.insert — add the video to a playlist owned by the same channel
  • videos.list, playlists.list, channels.list — read back the channel's own metadata to confirm uploads

The tool does not query, read, store, or process data about any other YouTube channel, any viewer, or any third party.
