Non-profit Quran recitation channel · Operated by one individual

Explore Islam (formerly "Islam Samjho") is a YouTube channel publishing full-chapter Quran recitations by renowned Qaris (notably Shaykh Mahmoud Khalil Al-Husary's Mujawwad recitation), with Urdu and English translation subtitles, for the benefit of the global Muslim community. All content is free and ad-supported.

About our YouTube API usage

We operate a private, internal-only upload automation tool that uses the YouTube Data API v3 to publish Quran recitation videos to our own channel. The tool is run by a single operator (the channel owner) on his own computer with his own Google credentials. It does not query data about any other channel, viewer, or third party.
