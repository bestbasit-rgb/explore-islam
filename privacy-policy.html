YOUTUBEPrivacy Policy

Explore Islam — Quran recitation channel · Last updated: 11 November 2026

Summary: Explore Islam is a non-profit YouTube channel operated by a single individual. Our upload automation tool does not collect, store, share, or sell personal data from viewers or third parties. This policy exists to comply with YouTube API Services policy requirements.

1. Who we are

Explore Islam (formerly "Islam Samjho") is a non-profit YouTube channel publishing full Quran recitations and Islamic educational content for the global Muslim community, with a focus on Urdu-speaking viewers. The channel is operated by a single individual and is not a company or legal entity.

  • YouTube Channel: Explore Islam
  • Contact: Bebasit [at] hotmail.com

2. Our API client

We operate an internal-only upload automation tool ("API client") that uses the YouTube Data API v3 to publish Quran recitation videos to our own channel. Important facts about this tool:

  • The tool is not distributed to end users, developers, or any third party.
  • The tool is not publicly accessible — only the channel owner can run it.
  • The tool authenticates with only the channel owner's own Google account credentials.
  • The tool has no sign-up, no user accounts, no viewer-facing interface.

3. What data we collect

From YouTube viewers

We do not collect any data from viewers. Our upload tool does not read comments, likes, subscriber lists, analytics, watch history, or any other viewer-facing data through the API.

From the channel owner

The upload tool uses the following data, stored only on the channel owner's personal computer:

  • Google OAuth 2.0 refresh token (for the channel owner's Google account)
  • Local file paths for audio, subtitle, and video files to be uploaded
  • Metadata (titles, descriptions, tags) written by the channel owner

None of this data is transmitted anywhere except to Google's own YouTube Data API endpoints.

4. YouTube API Services

Our API client uses the following YouTube Data API v3 endpoints, solely for publishing videos to our own channel:

  • videos.insert — upload the MP4 file
  • videos.update — set the title, description, and category
  • thumbnails.set — attach a custom thumbnail
  • playlistItems.insert — add the video to a Juz playlist
  • videos.list, playlists.list, channels.list — read our own channel's own data to verify uploads

By using this channel, viewers also agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

5. How we share data

We do not share any data with third parties. The only data transmission that occurs is between the channel owner's upload tool and Google's YouTube API, for the sole purpose of publishing videos to the channel owner's own channel.

6. Data retention and deletion

Because we do not collect data from viewers or third parties, there is no viewer data to retain or delete.

Data stored locally on the channel owner's computer (OAuth refresh token, source files) is retained only as long as needed to operate the upload tool, and is deleted when the tool is uninstalled or the computer is decommissioned.

To request deletion of any data that may have been inadvertently collected, or to raise any privacy concern, contact us at Bebasit [at] hotmail.com. We respond within 30 days.

7. Revoking access to your Google account

The channel owner can revoke the upload tool's access to the Google account at any time by visiting Google Account → Security → Third-party apps with account access.

8. Cookies and tracking

This website does not use cookies, tracking pixels, analytics, or any third-party scripts. It is a static HTML page served from GitHub Pages.

9. Children's privacy

We do not knowingly direct the channel's content or this upload tool at children under 13. Islamic content is intended for a general, all-ages audience.

10. Changes to this policy

We may update this policy from time to time. The "Last updated" date at the top of this page reflects the most recent revision. Significant changes will be noted in a new section below.
